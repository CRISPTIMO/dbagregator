# Терминальный агрегатор базы данных

## Запуск

Из корневой директории проекта выполните:

```bash
python3 -m pip install -r requirements.txt
python3 main.py
```

При первом запуске создаётся защищённое хранилище.

После включения шифрования данные хранятся в `CoreDB/infocore.vault`.
Используется AES-GCM и производный от пользовательского ключа ключ Scrypt.
Пароль нигде отдельно не сохраняется: если ключ потерян, восстановить данные
нельзя. Пункт `[7]` показывает журнал безопасности после успешной авторизации.
Неверные попытки показываются сразу; записать их внутрь контейнера до успешной
авторизации невозможно, поскольку сам журнал тоже зашифрован.

## Настройка полей

Сейчас в базе предусмотрены поля:

```json
{
  "fields": [
    "ФИО",
    "Номер телефона",
    "Адрес",
    "ТГ",
    "Заметки",
    "Дата рождения"
  ]
}
```

Номер строки автоматически создаётся базой и отображается как `ID`.

Пункт меню `[6] Добавить столбец` позволяет создать новое поле прямо из
терминала. В старых записях такое поле будет отображаться как `NULL`.

Пункт меню `[5] Открыть досье записи` показывает все данные выбранной строки
по её `ID`, включая пустые поля и дату последнего изменения.

Дата создания сохраняется в момент добавления записи, а дата изменения — при
каждом редактировании. Время записывается по локальному времени компьютера
вместе с часовым поясом.

Пустой ввод при создании новой записи сохраняется как `NULL`. При редактировании
пустой ввод оставляет старое значение, а текст `NULL` очищает поле.
